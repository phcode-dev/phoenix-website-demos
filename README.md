# Phoenix Code website demos

Websites designed and built in [Phoenix Code](https://phcode.dev), published at
[demo-sites.phcode.dev](https://demo-sites.phcode.dev).

## How to add a demo

1. Create a folder named after your site, with `index.html`, `styles.css` and, if needed,
   `script.js`.
2. Add a `preview.jpg` screenshot. This will be displayed as a thumbnail image.
3. Add a card for it in the root `index.html`.

> Each demo lives in its own folder and is served at `demo-sites.phcode.dev/<demo>/`.
